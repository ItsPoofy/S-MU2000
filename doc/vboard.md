# 架空のプラグインボード

実在しないプラグインボードを、MU2000 に挿したことにして鳴らす遊び。`src/vboard.h`。

実機のプラグインボード（PLG100 / PLG150）は、割り当てたパートの MIDI を受けて自分で音を作り、その音を本体の
DSP に渡す。本体はそのパートの音量・パン・エフェクトの送りを、内蔵の音色と同じように効かせる。ここも同じ形にしてある。

| | |
|---|---|
| 挿す所 | マスターの窓の「架空のプラグインボード」。ボードと、挿すパート（1〜64）を選ぶ |
| 鳴り方 | そのパートが受ける MIDI（そのパートの受信チャンネル）で鳴る。内蔵の音は、そのパートだけ消える |
| 効くもの | パートの音量（CC7）・エクスプレッション（CC11）・パン（CC10）・リバーブの送り（CC91）・コーラスの送り（CC93）。パネルや XG の SysEx で変えても同じ（ワーク RAM の値を読む） |
| まだ効かないもの | バリエーションの送り、インサーション、パートの EQ・フィルター・EG など（内蔵の音色のための設定） |
| 本体からの見え方 | firmware はボードを知らない。液晶に PLG の印は出ず、ボードの音色名も出ない |
| 残り方 | 設定は残らない（起動するたびに「挿さない」に戻る） |

## A/D INPUT との違い

どちらも外で作った音を MU のミキサーとエフェクトに入れるが、入口が違う。A/D INPUT は前面の端子で、本体は専用の
A/D パートとして扱い、MIDI では鳴らない。ボードの入口（`mu2000::set_external_audio`）は内部のコネクターにあたり、
普通のパートに割り当てて、そのパートの MIDI と設定で鳴る。A/D INPUT を塞がない。

## FC ボード

80 年代の家庭用ゲーム機の音源（矩形波 2・三角波・ノイズ）ふうの音。8 音まで重なる。全部ここで書いた計算で、
ROM もサンプルも使わない。

| プログラムチェンジ | 音 |
|---|---|
| 1 | 矩形波（デューティ 1/2） |
| 2 | 矩形波（1/4） |
| 3 | 矩形波（1/8） |
| 4 | 三角波（16 段の階段。実物と同じく音量を持たない） |
| 5 | ノイズ（長い周期） |
| 6 | ノイズ（短い周期。金属的） |
| 7 | デューティを 60 分の 1 秒ごとに切り替える矩形波 |
| 8 | 1 オクターブ上と交互に鳴る矩形波（高速アルペジオ） |
| 9〜16 | 同じ音で、押している間も音量が段々に下がる |

音量は 16 段で、強さ（ベロシティ）で決まる。音量の段・デューティ・アルペジオは 60 分の 1 秒ごとに進む。
ピッチベンド（±2 半音）、モジュレーション（CC1。ビブラート）、オールノートオフ（CC123）・オールサウンドオフ（CC120）を受ける。
音色の値を動かすコントロールチェンジ（初期の番号は CC20〜31・CC102〜109。付け替えられる）は下の「コントロールチェンジで音色を触る」。

## 音色の窓での見え方（1 パートのボード）

FC ボードやオリジナルのボードが借りているパートを「音色」の窓で開くと、左の音色選びの上に
**「PLG-n ○○ で鳴らす」** のボタンが出る。押すとそのパートでボードのバンク（MSB 90・91・92、LSB 0）が選ばれ、
窓の中身がボードのものに替わる（`src/ui/single_board_pane.h`）。

| | 内蔵の音色のとき | ボードのバンクのとき |
|---|---|---|
| 左の面 | 分類・音色・バンク違い | ボードのプログラムの並び。上に「内蔵の音色へ戻す」 |
| 右のタブ | 形・ドラム・マトリクス・すべて | **ボード**・すべて |
| ボードのタブ（FC） | | FC ボードの音色エディタ（下の「FC ボードの音色を作る」） |
| ボードのタブ（オリジナル） | | 名前、波形の絵、包絡線の絵とアタック・ディケイ・サステイン・リリース（変えるとすぐ音に出て、ボードのファイルに書かれる） |

上の行（音量・エクスプレッション・パン・送り・鍵盤）はどちらでも同じ。「内蔵の音色へ戻す」は、切り替える前の
音色を選び直す。バンクを MIDI やパネルで変えても、窓は今のバンクに合わせて替わる。

## FC ボードの音色を作る

FC ボードの音色は書き換えられる。「音色」の窓で、FC ボードが鳴らしているパート（1 パートのボード）か、
口 E のチャンネル（16 パートのボード）を開くと、右にエディタが出る（`src/ui/fc_voice_editor.h`）。
触れるのは当時のゲームの音作りで使われた手だけで、値は全部「コマ」（60 分の 1 秒）と音量の「段」（16 段）。

| 列 | 触れるもの |
|---|---|
| 波 | 矩形波・三角波・ノイズ・金属ノイズ。矩形波はデューティの並び（1/8・1/4・1/2・3/4 を 4 つまで、何コマごとに切り替えるか） |
| 音量 | 押している間の下がり方（何コマで 1 段）、止まる段、離してからの下がり方（1 コマに何段） |
| 音程 | アルペジオ（4 つまでの半音のずれと、何コマごとか）、鳴り始めのずれ（何半音ずれた所から何コマで戻るか）、自動のビブラート（深さと遅れ） |

列の上の絵は、波の形・音量の動き（1 秒押して離したとき）・音程の動き（最初の 1 秒）。

128 個の音色のまとまりが「音色の組」で、設定のフォルダーの `fcsets` に 1 つのファイル（`<名前>.smufc`）で置かれる。
**組は FC ボード 1 枚ごとに持つ**（実機のボードが 1 枚ずつ自分の音色を持つのと同じ）。PLG-1・PLG-2・PLG-3 の 1 パートの
ボードと 16 パートのボードは、それぞれ別の組を開ける。同じ組を 2 枚で開いてもよく、そのときは片方で変えるともう片方にも届く。

何も開いていない間は初期の 16 個で、プログラム 17 以降はそのくり返し（今までと同じ鳴り方）。エディタで何かを触ると、
その写しからそのボード用の組（「FC SET」。使われていれば「FC SET 2」…）ができ、音色の並びは 128 個になる。
触った値はすぐ音源に渡り、鳴っている音にも効く。使っていた組は次に起動したときも開く
（`board_fc=`・`board_fc2=`・`board_fc3=`・`board_fc16=`）。

## コントロールチェンジで音色を触る

エディタで触れる値は、シーケンサーからコントロールチェンジでも動かせる（曲の途中でデューティを変える、
アルペジオの和音を替える、など）。初期の番号は XG が使っていない所で、値はエディタの数字そのまま。
半音のずれだけは 64 を 0 として送る（63 = -1、65 = +1）。範囲の外の値は端に寄る。

**番号は付け替えられる。** エディタの「CC の割り当て...」で、値ごとに番号を決める（つまみの横にいつも「CC27」のように出ている）。

- 0 にすると、その値はコントロールチェンジで動かない
- 1 つの番号で動かせる値は 1 つ。使われている番号を選ぶと、元の値から外れる
- 使えない番号: 0・1・6・7・10・11・32・38・64・91・93・94・96〜101 と、120 以上
  （ボードや本体のパートが別の用に聞いているもの）
- 番号は FC ボード全部に共通で、設定に残る（`board_fc_cc=`。値の順にコンマで並べたもの。初期の番号のままなら空）
- 「初期の番号に戻す」で下の表に戻る

| CC（初期の番号） | 触る値 | 値 |
|---|---|---|
| 20 | 波 | 0 矩形波、1 三角波、2 ノイズ、3 金属ノイズ |
| 21 | デューティの並びの長さ | 1〜4（1 なら切り替えない） |
| 22 | デューティを何コマごとに進めるか | 1〜30 |
| 23〜26 | デューティの並びの 1〜4 番目 | 0 = 1/8、1 = 1/4、2 = 1/2、3 = 3/4 |
| 27 | 押している間、何コマで 1 段下がるか | 0〜60（0 = 下がらない） |
| 28 | 下がって止まる段 | 0〜15（0 = 消えるまで） |
| 29 | 離してから、1 コマに何段下がるか | 1〜15 |
| 30 | 自動のビブラートの深さ | 0〜100（セント） |
| 31 | ビブラートが掛かり始めるまで | 0〜120（コマ） |
| 102 | アルペジオの並びの長さ | 1〜4（1 なら切り替えない） |
| 103 | アルペジオを何コマごとに進めるか | 1〜30 |
| 104〜107 | アルペジオの 1〜4 番目のずれ | 40〜88（64 が 0。-24〜+24 半音） |
| 108 | 鳴り始めの音程のずれ | 16〜112（64 が 0。-48〜+48 半音） |
| 109 | 何コマで元の高さに寄るか | 0〜60（0 = ずらさない） |

決まり:

- 動くのは、**そのボード（16 パートのボードなら、そのチャンネル）がいま選んでいるプログラムの音だけ**。
  鳴っている音にもすぐ効く
- **音色の組もファイルも書き換えない。** 触っていない値は組の音色のまま（エディタで組を変えれば、そちらは付いてくる）
- **エディタには、コントロールチェンジで来た値が出る。** つまみと絵はいま鳴る音のとおりに動き、エディタの上に
  「コントロールチェンジで動いている値: CC23 CC104 …」の行が出る。つまみの見出しは色が付いて CC の番号が並ぶ
  （波・デューティ・アルペジオの並びは、上の行の番号で見分ける）。その値は曲のもので、組には入っていない
  - その欄をエディタで動かすと、**動かした欄だけ**を組に書き、その欄をコントロールチェンジから引き取る
    （曲が同じ CC をまた送ってくれば、また曲の値になる）。ほかの欄は組の値のまま
  - 「組の値に戻す」は、コントロールチェンジで来た値を全部捨てる（プログラムチェンジを受けたのと同じ。組は変わらない）
  - 「初期の音色に戻す」「貼る」は音色を丸ごと入れ替えるので、コントロールチェンジで来た値も全部捨てる
- **プログラムチェンジを受けると、触った値は全部捨てて組の音色に戻る**（同じ番号を選び直しても戻る）。
  曲の頭で「バンク → プログラムチェンジ → コントロールチェンジ」の順に送れば、いつも同じ音から始まる。
  XG System On・GM System On でも戻る。Reset All Controllers（CC121）では戻らない
- 1 パートのボードは、そのパートの受信チャンネルに来たものを聞く。同じメッセージは本体の firmware にも届くが、
  XG はこの番号を使っていない（AC1・AC2 の番号をここへ変えていなければ何も起きない）
- 鳴り始めのずれは、CC108（ずれ）と CC109（コマ）の両方を送る。エディタと違って、コマは自動では入らない

Domino では、下の `fcdef.py` が作る定義のコントロールチェンジの欄に「FC board voice edit」として並ぶ。

## 増設の差込口（PLG-4〜6）

実機の差込口は 3 つで、本体の firmware が話しかけるボードも 3 枚まで（増やせない。調べた記録は `doc/plg-protocol.md`）。
4 枚目から先は、**エミュレーターだけが知っている差込口**に挿す。ボードの窓の下の段「増設の差込口」。

| | PLG-1〜3 | PLG-4〜6（増設） |
|---|---|---|
| 挿せるボード | 全部 | 1 パートのボード（FC ボード・オリジナルのボード） |
| バンク | MSB 90・91・92 | MSB 93・94・95（どれも LSB 0） |
| 鳴り方 | 割り当てたパートでボードのバンクを選んでいる間 | 同じ |
| 音量・パン・リバーブとコーラスの送り | 効く | 効く |
| 本体の液晶の音色名 | 出る | `Silence` と出る（内蔵の音は鳴らない） |
| UTIL → PLG（PartAssign） | 並ぶ | 並ばない。パートはボードの窓で決める |
| 挿すときの起動し直し | 要る（本体に見つけてもらう） | 要らない |
| 「音色」の窓の音色選び・エディタ | 使える | 使える |
| FC ボードの音色の組 | ボードごと | ボードごと（`board_fc4=`〜`board_fc6=`） |

本体が知らないので、パネルで音色を変えても本体からボードへは知らせが来ない。増設の差込口のボードは、
MIDI のバンクセレクトとプログラムチェンジを自分で聞くのに加えて、ワーク RAM のバンクとプログラムが変わったのを見て追う
（`mu2000::vb_follow_ram`）。設定には `board4=`・`board4_part=` 〜 `board6=`・`board6_part=` で残る。

## Domino から FC ボードの音色を選ぶ

`tools/domino/fcdef.py` が、Domino（takabosoft）の音源定義ファイルに FC ボードの音色の並びを入れる。
Domino のトラックの音色欄でマップ「FC BOARD PLG-n」を選ぶと、そのボードのバンク（MSB 90〜95・LSB 0）と
プログラムチェンジが入る。

```bash
# FC ボードだけの定義ファイル
python tools/domino/fcdef.py "S-MU2000 FC board.xml"
# いま使っている定義ファイルの写しに、FC ボードの並びを足す（XG の音色と両方選べる）
python tools/domino/fcdef.py --into S-MU2000.xml "S-MU2000+FC.xml"
```

出来たファイルを Domino の `Module` フォルダーに置き、環境設定の音源で選ぶ。

| マップ | 送るもの |
|---|---|
| FC BOARD PLG-1 (MSB 90) 〜 PLG-6 (MSB 95) | バンクセレクトとプログラムチェンジ。1 パートの FC ボード（差込口ごと） |
| FC BOARD 16 parts (port E) | プログラムチェンジだけ。16 パートの FC ボード |

コントロールチェンジの欄には、音色の値を動かす 20 個（上の「コントロールチェンジで音色を触る」）がフォルダー
「FC board voice edit」に入る。波とデューティは名前で選べ、半音のずれは -24〜+24 のように符号つきで書ける。
`--into` のときも、元の定義の並びの最後に足す（ID が元の定義とぶつかるものは、空いている番号に振り替える）。
番号を付け替えてあれば、設定ファイルの `board_fc_cc=` を読んでその番号で作る（`--cc 20,21,…` でも渡せる）。
割り当てていない値は並ばない。番号を変えたら定義も作り直すこと。

並ぶのは初期の 16 個。自分で作った音色の組を使っているボードは、`--set 1=<組のファイル>`（16 パートのボードは
`--set 16=`）を付けると、その組の名前で 128 個並ぶ。`--set` を付けなくても、設定ファイル（`gui.ini`）の
`board_fc=` などに組が入っていれば、そこから読む。音色名はここで付けたものか使う人が付けたものなので、
FC ボードだけの定義ファイルは配って差し支えない。

## 中の作り

- `mu2000::set_virtual_board(kind, part)` で挿す・外す
- `mu2000::midi_in` が、入ってきた MIDI をボードにも聞かせる（firmware にも今までどおり渡すので、パートの設定や液晶のメーターは動く）
- `mu2000::run_sample` の頭で 1 サンプルぶん鳴らし、パートの設定を掛けて、エフェクトの入口（dry・reverb・chorus）へ入れる
- そのパートの内蔵の音は、パートのミュート（声を SWP30 の手前で消す）で消す
- samptest が確かめる: 矩形波の 440Hz と 3 倍音、音量 0 で消える、パンで片側が消える、リバーブの送りで尾が残る、ほかのチャンネルでは鳴らない、外すと内蔵の音に戻る

## これから

本体の firmware にボードを認識させる（ボードと本体のやり取りを再現する）と、パートの割り当てや音色名が実機どおりに
なる。それは実在のボード（PLG150-VL など）の解析と同じ土俵の話で、ここではやっていない。
